# Gantt Chart for Sheets

Public pages for the Google Sheets add-on: the homepage, support, privacy policy and terms.

These files are **generated** from the source documents in the add-on's own repository by
`tools/build-site.js`. Edit them there, not here — a hand-edit made in this repository is
overwritten on the next build, and a legal document that exists in two places is a legal
document that disagrees with itself.

Served at <https://slowgrain.github.io/gantt-for-sheets/>.

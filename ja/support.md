# Gantt Chart for Sheets — サポート

**お問い合わせ: slowgrain.dev@gmail.com** — 5営業日以内に返信します。

## はじめに

1. タスクリストが入ったスプレッドシートを開きます。
2. **拡張機能 → Gantt Chart for Sheets → ガントチャートを作成**を選択します。
3. **Gantt** タブにチャートが作成されます。元のタスクリストは変更されません。

計画を変更したら再実行してください。チャートは毎回作り直されます。

## 既存のタスク表を接続

表は A1 から始める必要はなく、列順も自由です。日本語、英語、韓国語、スペイン語、ポルトガル語、フランス語、ドイツ語の見出しを自動認識します。

自動認識されない場合は、**Gantt ツール → 既存のタスク表を接続・プレビュー**を選び、見出し行と列の役割を指定します。保存前に最大6件のタスク、計算後の日程、開始日不足や未配置の件数を確認できます。設定はタブごとに保存されます。「使用しない」を選ぶと、その列の自動推測を無効にできます。

| 項目 | 例 | 必須 |
|---|---|---|
| タスク名 | タスク、作業、Tarea、Aufgabe | はい |
| 開始日 | 開始、開始日、Start | はい* |
| 終了日または期間 | 終了、日数、期間 | どちらか |
| 先行タスク | 先行、Predecessors | いいえ |
| 進捗 | 進捗、Progress | いいえ |
| 担当者 | 担当者、Owner | いいえ |
| WBS / 上位タスク | レベル、親タスク | いいえ |
| 作業時間・日次容量 | 合計工数、Hours per day | いいえ |

* 開始日がなくても、先行タスクから日付を計算できる場合や、子タスクを持つフェーズ行なら問題ありません。

## 日付の読み取り

ISO形式（2026-04-03）またはスプレッドシートの日付セルを使うと曖昧さがありません。03/04 のような形式はシート内の値から日/月順を判断し、判断材料がない場合は言語の一般的な順序を使います。

## 先行タスクを入力

「先行」列に前のタスクのIDを入力します。`12` はタスク12の終了後に開始、`12+3` は3日後、`12-1` は1日前に開始します。複数のIDはカンマで区切ります。

## 作業量と時間

担当者を入力すると、同時に抱えるタスクと日次容量を確認できます。**合計作業時間**は担当者数と予定作業日に均等配分されます。**担当者ごとの1日あたりの時間**を入力すると、合計作業時間より優先されます。時間が空欄のタスクは推測せず集計から除外します。

## よくある質問

**タスクがチャートに表示されません。** チャートの下に理由が表示されます。開始日、終了日、期間、先行タスクの循環参照を確認してください。

**週末を除外したい。** メニューで**週末を除外**を有効にします。祝日を除外する設定はタブごとです。

**チャートが横に長すぎます。** タイムラインはプロジェクト期間に合わせて日・週・月・四半期に切り替わります。期間の上限はありません。

**50件を超えるタスクがあります。** 無料版は50件までです。Proでは上限がなくなります。上限を超えたタスクは黙って消さず、通知されます。

## ライセンスキー

Pro の購入先: https://slowgrain.app/gantt-for-sheets/#pro

キーの入力: **拡張機能 → Gantt Chart for Sheets → ライセンス → ライセンスキーを入力**。キーはGoogleアカウントに保存されるため、一度入力すれば各スプレッドシートで利用できます。

キーが届かない、紛失した、または拒否された場合は、注文番号を添えてサポートまでご連絡ください。キーは `GS1.` で始まり、空白は含みません。

## 問題を報告

**slowgrain.dev@gmail.com** まで、次の情報をお送りください。

- 期待した動作と実際の動作
- チャートまたはエラーのスクリーンショット
- 可能であれば、機密情報を削除したスプレッドシートのコピー

アドオンはデータを自動送信しません。必要なファイルはメールに添付してください。

# Gantt Chart for Sheets プライバシーポリシー

**最終更新日: 2026年10月14日**

## 要約

このアドオンにはインターネットへアクセスする権限がありません。タスク表を読み取り、ガントチャートにして同じスプレッドシートへ書き込みます。個人情報を収集・保存・販売・共有することはありません。

## アドオンがアクセスできる情報

要求する権限は次の2つだけです。

| 権限 | スコープ | 用途 |
|---|---|---|
| 使用中の特定の Google Sheets ファイルのみ表示・編集・作成・削除 | `spreadsheets.currentonly` | タスク一覧を読み取り、同じファイルのタブにチャートを書き込む |
| メッセージやサイドバーにウェブコンテンツを表示・実行 | `script.container.ui` | アドオンのメニューとダイアログを表示 |

Google Workspace Marketplace のインストール画面には、Google の要件により氏名とアカウントのメールアドレスも表示されます。アドオンのコードはこれらを読み取らず、当方に送信・保存されることもありません。

アドオンは Google Drive、現在使用中のファイル以外のスプレッドシート、メール、連絡先、カレンダーにはアクセスしません。また `script.external_request` の権限がないため、外部へのネットワーク接続はできません。

## 保存する情報と場所

Google アカウント内の Google アドオン用ストレージに、次の情報を保存します。

1. スプレッドシートごとの週末除外とクリティカルパス強調の設定
2. 使用する場合の Pro ライセンスキー。キーにはプラン名、有効期限、購入参照番号が含まれる場合がありますが、氏名やメールアドレスは含まれません。

アドオンをアンインストールすると、これらの情報は削除されます。ライセンスキーは **拡張機能 → Gantt Chart for Sheets → ライセンス** を開き、入力欄を空にして確定すればいつでも削除できます。

## ライセンス購入時に受け取る情報

決済はアドオンではなく決済サービス事業者が処理します。Pro の購入時に、キーの送付先として注文参照番号とメールアドレスが当方へ渡されます。カード情報を見ることも保存することもありません。別の Google Apps Script がキーを生成してメールで送り、注文参照番号とメールアドレスは当方の非公開ストレージに保管されます。

この情報はキーの発行・再発行と法律で必要な記録保管にのみ使用します。マーケティングには使わず、第三者にも共有しません。税法などで求められる期間のみ保管し、法律で認められる場合は早期削除を依頼できます。

## 情報の保護

**通信中:** スプレッドシートのデータが Google のインフラ外へ送信されることはありません。アドオンは Google Apps Script として実行され、結果のチャートも同じファイルに書き込みます。ブラウザーとスクリプト間の通信は Google が TLS で保護します。アドオンに外部ネットワーク権限はありません。

**保存時:** スプレッドシートのコピーは保持しません。タスク名、日付、担当者などはチャート作成中にメモリー上で処理され、完了後は残りません。設定とライセンスキーは Google の `PropertiesService` に保存され、Google により保存時に暗号化されます。当方は読み取れません。

**アクセス管理:** 当方にはスプレッドシートのデータへアクセスする手段がありません。従業員、委託先、データへ到達する仕組みもありません。アドオンを公開する Apps Script プロジェクトは1つの Google アカウントが所有しています。ライセンス署名用の秘密値はソースリポジトリにコミットされず、公開コードにも含まれません。

## 保持と削除

- スプレッドシートのデータは保持しません。
- 設定とライセンスキーはアドオンの削除時に Google により削除されます。キーは上記の手順でも削除できます。
- 注文参照番号と送付先メールアドレスは、税法上の保管期間が終わった後に削除します。プライバシー窓口へ連絡すれば、法律が認める範囲で早期削除を依頼できます。

チャートはユーザー自身のスプレッドシートのタブに作成されるため、そのファイルの共有設定が適用されます。ファイルを共有した相手はタスク表と同様にチャートを閲覧できます。当方がチャートを公開・共有することはありません。

## Google Workspace API と AI モデル

このアドオンは Google Workspace API のデータを、汎用または非個人向け AI・機械学習モデルの開発、改善、学習に使用しません。AI や機械学習は使用せず、スケジュールは通常の計算で処理します。

Google API から受け取った情報の使用と移転は、[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy) の Limited Use 要件を含め、同ポリシーに従います。

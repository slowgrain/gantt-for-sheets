# Gantt Chart for Sheets 도움말

**문의: slowgrain.dev@gmail.com** — 영업일 기준 5일 안에 답변합니다.

## 시작하기

1. 작업 목록이 있는 스프레드시트를 엽니다.
2. **확장 프로그램 → Gantt Chart for Sheets → 간트 차트 만들기**를 선택합니다.
3. **Gantt** 탭에 차트가 만들어집니다. 원본 작업 목록은 수정되지 않습니다.

계획이 바뀌면 다시 실행하세요. 차트는 매번 새로 만들어집니다.

## 기존 작업표 연결하기

표는 어느 셀에서든 시작할 수 있고 열 순서도 자유롭습니다. 영어, 한국어, 일본어, 스페인어, 포르투갈어, 프랑스어, 독일어 제목을 자동 인식합니다.

자동 인식 결과가 맞지 않으면 **Gantt 도구 → 작업표 연결 및 미리보기**를 선택하세요. 제목 행과 각 역할에 해당하는 열을 고른 뒤 저장할 수 있습니다. 저장 전에 실제 작업 최대 6개, 계산된 날짜, 시작일이 없거나 일정에 배치되지 않은 작업 수를 확인합니다. 선택은 시트별로 저장됩니다. **사용 안 함**을 고르면 해당 역할을 자동 추정하지 않습니다.

| 항목 | 제목 예시 | 필수 |
|---|---|---|
| 작업명 | 작업, Task, 作業, Tarea | 예 |
| 시작일 | 시작, 시작일, Start, 開始 | 예* |
| 종료일 또는 기간 | 종료, 기간, End, Durée | 둘 중 하나 |
| 선행 작업 | 선행작업, Predecessors, Vorgänger | 아니요 |
| 진행률 | 진행률, Progress, Progreso | 아니요 |
| 담당자 | 담당자, Owner, Responsable | 아니요 |
| WBS / 상위 작업 | 레벨, 상위, Level, Parent | 아니요 |
| 투입시간 및 하루 용량 | 총 투입시간, 하루 시간, Total effort | 아니요 |

* 선행 작업에서 날짜를 계산할 수 있거나 하위 작업을 가진 단계 행이면 시작일을 비워도 됩니다.

## 날짜 형식

모호함을 피하려면 ISO 형식(2026-04-03)이나 스프레드시트의 실제 날짜 셀을 사용하세요. 03/04처럼 모호한 값은 시트 안의 분명한 날짜를 기준으로 일/월 순서를 추정합니다. 근거가 없으면 언어별 일반적인 날짜 순서를 사용합니다.

## 선행 작업 입력

선행 작업 열에 앞 작업의 ID를 입력합니다. 12는 12번 작업이 끝난 뒤 시작, 12+3은 3일 지연, 12-1은 하루 앞당김을 뜻합니다. 여러 작업은 쉼표로 구분합니다.

## 작업량과 시간

담당자를 입력하면 사람별 동시 작업과 하루 용량을 확인할 수 있습니다. **총 투입시간**은 담당자 수와 예정 영업일에 균등하게 나뉩니다. 사람별 **하루 투입시간**을 직접 입력하면 총 투입시간보다 우선합니다. 시간이 비어 있는 작업은 임의로 추정하지 않고 계산에서 제외합니다.

## 자주 묻는 질문

**작업이 차트에 보이지 않습니다.** 차트 아래에서 제외 이유를 확인하세요. 시작일, 종료일, 기간, 순환 선행 관계를 살펴보세요.

**주말을 제외하고 싶습니다.** 메뉴에서 **주말 건너뛰기**를 켜세요. 휴일은 시트별로 설정할 수 있습니다.

**차트가 너무 넓습니다.** 프로젝트 기간에 따라 타임라인이 일·주·월·분기 단위로 자동 전환됩니다. 프로젝트 기간 제한은 없습니다.

**작업이 50개보다 많습니다.** 무료 버전은 50개까지이며 Pro에서 제한이 없어집니다. 한도를 넘긴 작업은 조용히 삭제하지 않고 알려줍니다.

## 라이선스 키

Pro 구매: https://slowgrain.app/gantt-for-sheets/ko/#pro

키 입력: **확장 프로그램 → Gantt Chart for Sheets → 라이선스 → 라이선스 키 입력**. 키는 Google 계정에 저장되어 한 번만 입력하면 됩니다.

키가 도착하지 않거나 분실·거부된 경우 주문 참조 번호와 함께 지원팀에 연락하세요. 키는 GS1.로 시작하며 공백이 없습니다.

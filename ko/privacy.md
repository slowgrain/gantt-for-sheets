# Gantt Chart for Sheets 개인정보 처리방침

**최종 업데이트: 2026년 10월 14일**

## 요약

이 부가기능은 인터넷에 연결할 권한이 없습니다. 작업표를 읽어 차트로 만든 뒤 같은 스프레드시트에 기록합니다. 부가기능은 개인정보를 수집·저장·판매·공유하지 않습니다.

## 부가기능이 접근할 수 있는 정보

요청하는 권한은 다음 두 가지뿐입니다.

| 권한 | 범위 | 용도 |
|---|---|---|
| 현재 사용하는 특정 Google Sheets 파일만 확인·수정·생성·삭제 | `spreadsheets.currentonly` | 작업 목록을 읽고 같은 파일의 탭에 차트 기록 |
| 메시지와 사이드바에 웹 콘텐츠 표시 및 실행 | `script.container.ui` | 부가기능 메뉴와 대화상자 표시 |

Google Workspace Marketplace 설치 화면에는 이름과 이메일 주소도 표시됩니다. 이는 Google이 모든 등록 부가기능에 추가하는 항목입니다. 부가기능 코드는 두 정보를 읽지 않으며 저희에게 전달되거나 저장되지 않습니다.

부가기능은 Google Drive, 현재 작업 중인 파일 외의 스프레드시트, 이메일, 연락처, 캘린더에 접근하지 않습니다. `script.external_request` 권한도 없어 외부 네트워크 요청을 할 수 없습니다.

## 저장되는 정보와 위치

Google 계정 내부의 Google 애드온 저장소에 다음 정보가 기록됩니다.

1. 스프레드시트별 주말 제외 및 임계 경로 강조 설정
2. Pro 라이선스 키(사용하는 경우). 키에는 플랜, 만료일, 결제 참조 번호가 포함될 수 있으며 이름이나 이메일 주소는 포함되지 않습니다.

부가기능을 제거하면 이 항목들은 함께 삭제됩니다. 라이선스 키는 **확장 프로그램 → Gantt Chart for Sheets → 라이선스**에서 입력란을 비우고 확인하면 언제든 직접 지울 수 있습니다.

## 라이선스 구매 시 처리되는 정보

결제는 부가기능이 아니라 결제 서비스 제공업체가 처리합니다. Pro를 구매하면 키를 보내기 위해 주문 참조 번호와 이메일 주소가 저희에게 전달됩니다. 카드 정보는 저희가 보거나 보관하지 않습니다. 별도 Google Apps Script가 라이선스 키를 생성해 이메일로 발송하고, 주문 참조 번호와 이메일 주소는 저희 계정의 비공개 저장소에 보관됩니다.

이 정보는 키 발급·재발급과 법률상 필요한 기록 보관에만 사용하며 마케팅에 사용하거나 제삼자와 공유하지 않습니다. 법률상 보관 의무가 있는 기간에만 보관합니다. 법이 허용하는 경우 더 일찍 삭제를 요청할 수 있습니다.

## 정보 보호

**전송 중:** 작업표 데이터는 Google 인프라 밖으로 전송되지 않습니다. 애드온은 Google Apps Script에서 실행되고 결과 차트도 같은 파일에 기록됩니다. 브라우저와 스크립트 사이 연결은 Google이 TLS로 보호합니다. 애드온은 외부 네트워크 권한이 없습니다.

**저장 시:** 저희는 스프레드시트 내용을 복사해 보관하지 않습니다. 작업명, 날짜, 담당자 등은 차트를 만드는 동안 메모리에만 있고 실행 후에는 유지되지 않습니다. 설정과 라이선스 키는 Google `PropertiesService`에 저장되며 Google이 저장 시 암호화합니다. 저희는 이 값을 읽을 수 없습니다.

**접근 통제:** 저희에게 스프레드시트 데이터에 접근할 경로가 없습니다. 직원이나 계약업체도 없습니다. 게시용 Apps Script 프로젝트는 단일 Google 계정이 소유합니다. 라이선스 서명 비밀값은 저장소에 커밋되지 않으며 게시 코드에도 포함되지 않습니다.

## 보관 및 삭제

- 스프레드시트 데이터는 보관하지 않습니다.
- 설정과 라이선스 키는 부가기능을 삭제하면 Google이 제거합니다. 키는 위의 방법으로 직접 지울 수도 있습니다.
- 주문 참조 번호와 발급 이메일은 세법상 보관이 필요한 기간에만 보관한 후 삭제합니다. 개인정보 문의 주소로 연락하면 법이 허용하는 범위에서 조기 삭제를 요청할 수 있습니다.

차트는 사용자의 스프레드시트 탭에 기록되므로 파일의 공유 설정을 따릅니다. 사용자가 공유한 사람은 원본 작업표와 마찬가지로 차트를 볼 수 있습니다. 저희가 차트를 공개하거나 공유하지 않습니다.

## Google Workspace API 및 AI 모델

이 부가기능은 Google Workspace API 데이터를 일반 또는 비개인화 AI·머신러닝 모델의 개발·개선·학습에 사용하지 않습니다. AI나 머신러닝도 사용하지 않으며 일정은 일반적인 계산으로 처리합니다.

Google API에서 받은 정보의 사용과 이전은 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)의 제한적 사용 요건을 포함해 해당 정책을 따릅니다.

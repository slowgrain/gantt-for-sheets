# 기존 작업표에서 바로 만드는 간트 차트

Gantt Chart for Sheets™는 작업표를 재배치하지 않고, 차트를 스프레드시트 안에 직접 만듭니다.

[Google Workspace Marketplace에서 설치](https://workspace.google.com/marketplace/app/gantt_chart_for_sheets/946333481156) — 무료로 작업 50개까지 사용할 수 있습니다.

**오픈 기념 Pro 할인:** 연간 40%, 3개월 30% (2027년 1월 31일까지)

## 이미 쓰던 작업표를 그대로 연결하세요

표가 A1에서 시작하거나 열이 특정 순서일 필요가 없습니다. 작업명, 날짜 또는 기간, 담당자, 진행률, 선행 작업, WBS, 투입시간과 하루 용량을 기존 열에 연결하세요. 저장 전에 실제 작업 6개와 계산된 일정을 미리 볼 수 있고, 설정은 시트별로 기억됩니다. 원본 작업표는 덮어쓰지 않습니다.

## 시작 형식부터 일정 확인까지 시트 안에서

기본 작업 템플릿이나 팀 작업량, 계획 대비 실적 템플릿을 만들고 예시를 수정한 뒤 차트를 생성하세요. 필요한 열이 없는 시트에서는 템플릿 생성을 안내합니다. 사이드바를 오가거나 별도 도구로 작업표를 옮길 필요가 없습니다.

## 팀 일정과 진행 상황을 한눈에

선행 관계, 영업일, 휴일, WBS 단계, 임계 경로와 지연을 계산합니다. 총 투입시간은 담당자 수와 예정 작업일에 균등 배분하고, 사람별 하루 시간을 직접 입력하면 그 값이 우선합니다. 동시 작업과 용량 초과도 확인할 수 있습니다.
